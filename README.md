A tiny Python program that writes one complete story in exactly six words to /output/entry.txt: "Widow remarried. First husband knocked tonight." A widow rebuilds her life and remarries, and on that night the first husband she had buried in every sense that mattered knocks at her door.

## Run it

```sh
python3 main.py
```
